### 2. Update Turf
**PATCH** /api/v3/turfs/:turfId

**Request Body (multipart/form-data - include text fields and optional files `"entrance"`, `"dayTurf"`, `"nightTurf"`):**
{
  "name": "Champions Arena (Updated)",
  "openTime": "07:00",
  "closeTime": "22:00",
  "weekdayDayPrice": 1300
}

**Response (200 OK):**
{
  "id": "turf-uuid-1",
  "name": "Champions Arena (Updated)",
  "openTime": "07:00",
  "closeTime": "22:00",
  "weekdayDayPrice": 1300,
  "...": "(rest of turf fields similarly formatted as above)"
}

### 3. Upload/Update Turf Images (Bulk)
**POST** /api/v3/turfs/:turfId/images

**Request Body (multipart/form-data):**
- entrance: [File]
- dayTurf: [File]
- nightTurf: [File]

**Response (200 OK):**
{
  "id": "turf-uuid-1",
  "entranceUrl": "https://zgryqgoajdousrqdofcs.supabase.co/.../entrance.webp",

  "...": "(rest of turf fields similarly formatted as above)"

### 4. Upload Single Turf Image (One-by-One)
**PATCH** /api/v3/turfs/:turfId/upload-image/:type
(type: entrance, dayTurf, or nightTurf)

**Request Body (multipart/form-data):**
- file: [File]

**Response (200 OK):**
{
  "id": "turf-uuid-1",
  "entranceUrl": "https://zgryqgoajdousrqdofcs.supabase.co/.../entrance.webp",
  "...": "(rest of turf fields similarly formatted as above)"
}

### 7. Update Turf Status
**PATCH** /api/v3/turfs/:turfId/status

**Request Body (multipart/form-data - include text fields and optional files `"entrance"`, `"dayTurf"`, `"nightTurf"`):**
{
  "status": "ACTIVE" 
}
(Options: ACTIVE, INACTIVE)

**Response (200 OK):**
{
  "success": true,
  "data": {
    "id": "turf-uuid-1",
    "status": "ACTIVE"
  }
}
